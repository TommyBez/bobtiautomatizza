## Git e i commit

Git è uno strumento che registra le modifiche ai tuoi file nel tempo, così puoi ritrovare una versione precedente. È gratuito e open source. Ogni volta che registri un passo, fai un commit: segna cosa è cambiato, quando e chi l'ha fatto, con un messaggio che lo descrive.

## GitHub

GitHub è un servizio online basato su Git. Conserva nel cloud i tuoi progetti Git, che si chiamano repository, e aggiunge gli strumenti per lavorare in squadra.

## Branch e pull request

Un branch è un ramo del progetto, uno spazio a parte dove sviluppi una novità, correggi un errore o provi un'idea. Quando il lavoro è pronto, apri una pull request per proporre le modifiche, discuterle e rivederle prima di unirle al ramo principale.
